# Проверка webapp и API — 2026-09-07

Последующее обновление: ручное закрытие реализовано после этой проверки; описание и условия выпуска — в [manual-close.md](manual-close.md). Ниже сохранены результаты первоначальной проверки.

## Исправления

- POST /api/settings: согласован envelope user.settings; длительности отправляются в наносекундах, поля трейлинга — в формате Go JSON. Неотображаемые параметры stale и position_guard сохраняются.
- API сохраняет серверные поля пользователя (ID, Premium, Status, имя), отклоняет запрос без settings и возвращает 500 при ошибке сохранения.
- Сохранение выполняется и при остановленном боте. Настройки активной сессии читаются из актуального snapshot; остановка сохраняет этот snapshot.
- Запуск бота прекращается при ошибке загрузки пользователя, вместо продолжения с nil.
- Ошибка загрузки на странице «Ещё» отображается с кнопкой повтора. Ошибка сохранения стратегии не скрывает редактируемую форму.
- /settings загружается после общей авторизации без повторной зависимости от Telegram user в браузере.
- Числовые режимы тюна и PascalCase поля runtime/rejects преобразуются для UI.
- Для отключённых кнопок ручного закрытия добавлено объяснение; обработчиков закрытия в API нет.
- Контейнер кнопок заголовка допускает перенос; dist исключён из lint/git.

## Проверено

- go test ./... — успешно.
- svelte-check — 0 ошибок, 0 предупреждений.
- ESLint — без ошибок; остаются предупреждения any и ключей each.
- Production build — успешно.
- Node tests: сериализация настроек/интервалов и преобразование админских ответов — 3 теста успешно.
- HTTP controller tests: валидный запрос, неверный envelope, отсутствие settings, ошибка БД, защита серверных полей, ошибка получения пользователя при запуске.
- Браузер с локальным mock API: раздел «Ещё», сохранение, запуск/остановка тестового бота, повтор после недоступности API.
- Браузер: переключение вкладок стратегии, сохранение BE trigger 0.8 и его повторная загрузка; неверный интервал не скрывает форму, исправление на 30s успешно сохраняется.
- Браузер: обзор, пустой список активных сделок, переключение истории и её обновление.

## Границы проверки

Браузер использовал локальные фикстуры, не PostgreSQL и не OKX. Интеграция с реальным аккаунтом Telegram/OKX и продакшен-развёртывание не выполнялись. Проверки не означают, что реализованы все функции: «Частично» и «Закрыть» остаются недоступны до разработки соответствующих API и UI-сценариев. Админские преобразования проверены модульными тестами, не браузером под реальным администратором.
